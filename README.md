Zephyr RTOS on STM32U5 NUCLEO-U575ZI-Q Development board

Implemented:

LEDS:
      Green LED: Connected to GPIO pin PB7
      Blue LED : Connected to GPIO pin PC7
      Red LED  : Connected to GPIO pin PG2

BUTTON: 
      GPIO pin PC13

CONSOLE OUTPUT: 
      USART1 TX PA9
      USART1 RX PA10

BSP files path : zephyr_boards_others_xj_575/xj_55
